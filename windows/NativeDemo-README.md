# Awesome Interview Windows 1.6.0-W Preview 25

Windows 10/11 x64、WPF / .NET 10 原生追赶预览。面试、简历、面经录入与导出流程已接通，完整追赶PRD的全部发布门禁尚未通过。

## 安装

解压 `AwesomeInterview-NativeDemo-1.6.0-W-preview25-win-x64.zip`，先退出旧版（包括托盘），运行 `Install.cmd`；也可直接运行 `app/AwesomeInterview.NativeDemo.exe`。用户级、未签名、自包含x64包，无需预装.NET。本轮没有自动执行安装、升级或卸载。

使用现有账号在应用内登录。可主动勾选「在此电脑记住密码」。保存的凭据由 Windows 当前用户 DPAPI 加密，重登绑定原服务器与账号。退出登录会清除已保存凭据和账号缓存，也可在登录页单独清除密码。会话、快照、私人草稿、简历页和提醒账本同样加密保存。卸载保留 `%LOCALAPPDATA%/AwesomeInterviewNative` 与 `%LOCALAPPDATA%/AwesomeInterviewNativeDemo` 中的数据和桌面偏好。

## 随身日程样式

随身日程的「外观」提供四个预设按钮和透明度滑块。在主窗口「设置与版本 → 随身日程外观」可选择样式、导入 JSON、打开样式目录。编辑文件后选择该样式并点击「重新读取」。用户样式保存在 `%LOCALAPPDATA%/AwesomeInterviewNativeDemo/PortableStyles`。内置示例和字段说明会复制到这个目录。可配置四项透明度、文字与组件颜色、玻璃色调、强度、折射量、平滑半径与渐隐距离。详见 [样式字段说明](AwesomeInterview.NativeDemo/PortableStyles/README.md)，安装包内位于 `app/PortableStyles/README.md`。

「清透描边」以整体、底色、边框、字体透明度 0%、100%、0%、0% 为准。「清透描边」和「清透淡影」关闭磨砂，选择「磨砂玻璃」开启。内置预设采用通透玻璃。标题栏操作和日历视图切换各自共用一条圆角玻璃，日程标签用更方正的圆角。CPU 均匀采样桌面。文字下方的核心区扩大平滑范围并增强淡色或深色衬底，压低下层窗口的反差笔画。边缘保留低强度折射并渐隐。清透样式遇到高反差背景时也会在文字下方启用局部衬底，背景恢复平整后自动撤去。任务标题和起止时间共用一片玻璃，卡片的实际起止位置各有一条向内渐隐的薄边。左侧整点刻度使用更宽的玻璃底纹。磨砂不占用布局空间。内置预设按整块玻璃的背景明度选择黑字或白字，明度略有波动时保持现有字色。自定义样式可固定浅玻璃黑字或深玻璃白字。文字遮住的采样点用邻近纹理补齐。当前时刻标签保持无底色，Windows 高对比度模式关闭磨砂。

## 本轮能力

- 我的面试：标题/岗位搜索、状态筛选、分页、查看日程、入会、简历与关联面经；专门的添加面试入口预选面试，通用添加仍默认个人事项。
- 简历：PDF上传/替换、进度、取消与解析等待；WPF窗口分页缩放，缓存先显示，版本变化后下载；最多两个成功版本、合计图片数据预算40MB。
- 我的面经：卡片、包含搜索、可见性筛选和分页；资料、关联面试、可选日期、编辑和删除。新建先存私密草稿，最终保存时按公开选项提交。
- 面经编辑：逐题失焦加入、双击编辑、追问、排序、分类、三类回答、感受与模块/总用时；本机自动草稿，联网自动保存正文草稿。版本冲突保留本机内容，不覆盖服务器；不完整快照禁止覆盖完整原文。
- 全文/文件：全文左右解析预览；UTF-8 Markdown和带文字层PDF导入（5MB），确认追加或替换，不提供OCR。
- 导出：分页预览；标题、分区/连续排版，独立隐藏公司、岗位、日期及三类回答；PDF/Markdown下载和预览使用同一组选项。
- 离线排期：想法与日程持久队列、来源先同步、失败依赖回滚；确认数据和乐观投影分开持久化。回执检查账号、操作和实体；未知队列版本保留原文件并阻止新更改。18小时整份缓存，日期/视图本地切换；局部日历刷新不续期面经。
- 普通会议和面试：邀请解析、校对入会链接/会议号，保存和编辑保留这些字段；简历入口在面试工作台。
- 主日历视图切换靠左，待安排、刷新和概览靠右。窄窗按组换行。
- 日视图点击「回到今天」后从时间表顶部滚到当前时间。月视图将高亮日期滚到视口中央附近，遵循月历的滚动边界。
- 主窗口启动和恢复时按所在显示器的工作区定位，最小尺寸随可用空间调整。随身日程支持四边和四角拖拽缩放，双击顶栏可铺满或还原。铺满时拖动顶栏会先恢复原尺寸。鼠标穿透时可先点解锁再拖动。

- 随身日程默认用内容区显示时间表。点击「当日任务」切换到列表，返回时保留时间表滚动位置。时间轴保留固定宽度，时间表和列表仅纵向滚动。超出可见容量的重叠任务可在列表查看。当天没有待办时仍可打开想法录入，已完成任务可按需显示和恢复。穿透时保留滚轮浏览。鼠标悬停约 0.8 秒后可临时操作，鼠标周围显示一圈不拦截点击的磨砂提示。移开后恢复穿透并收起提示。空闲默认 10 秒后进入鼠标穿透，延时可在桌面设置中调整或关闭。穿透时收起标题栏和窗口外框，标题栏原位置居中保留“解锁交互”。鼠标悬停或键盘聚焦时显示按钮底纹，也可在托盘关闭穿透。组件失焦 5 秒后自动返回时间表并将当前时间线居中。置顶位于顶栏，整体、底色、字体和边框透明度可独立调节。底色全透明时仍可保留任务卡片描边。没有已保存外观时默认使用“实色”，整体、底色、边框和字体透明度均为 0%，窗口底色覆盖整个组件。升级保留已保存的透明度和自定义样式，两款旧内置样式的磨砂改为关闭。非磨砂样式在拖动、缩放或滚动停稳约 450 毫秒后，按每个可见字形周围的背景像素计算对比度。前台窗口切换时主动重新取色。同一窗口中的画面变化由 1 到 2 秒的采样周期检测。停稳后遇到持续的背景变化时，各字从当前颜色平滑过渡约 280 毫秒。同一批文字在数据未变时保留原来的绘制与字色。文字优先保留原色。对比不足时，按 OKLCH 原色相调整明度，并在超出 sRGB 色域时降低彩度。混合背景可为字形增加同色系的反差细描边。渲染沿用 WPF 的原有字形排版。采样数据仅在内存中用于取色和局部磨砂。当前时间数字放大至 15，与时间线共用红色，无底色或边框。临近的一个整点标签暂时让位。时间表在当前时间前后各一小时和任务时段保留整点刻度与横线，往外用约两小时渐隐。横线也会在任务区域右侧横向淡出。穿透时，完全淡出的时段与右侧空白不触发悬停交互，仍可在时间表内使用滚轮并从上方手动解锁。
- 提醒：应用运行或留在托盘时按日程选项尝试系统托盘提醒；完成/废除/重复单日状态参与判断，去重账本防重复，合并同轮提醒，三分钟宽限后不补发陈旧提醒。
- 管理员：保留原生汇总入口，新增面试、简历、草稿、解析、导出固定监控节点，不记录私密正文或查询词。

## 服务端与限制

需要同版本源码的 `/api/mobile/v1/workspace/*`、面经接口和 `/my-schedule/idea-sync/*`。旧服务缺接口时明确报错，不能只更新安装包。本轮没有执行额外公网部署；现有服务快照、面试列表、简历状态已通过真实账号只读联调，没有写入真实数据。

PDF当前由服务端PyMuPDF生成有界PNG页，WPF原生展示并加密缓存；已缓存简历可离线阅读。这并非完整本地PDF引擎，没有文本选择/搜索，放大受渲染分辨率限制。预览支持未加密1—80页、每页不超过800万渲染像素、总PNG数据最多40MB。

提醒使用 [Windows NotifyIcon](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.notifyicon.showballoontip?view=windowsdesktop-10.0)，受系统勿扰设置影响；彻底退出后不提醒，计划通知未接入。穿透按微软[分层窗口规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)实现，真实鼠标与多DPI验收待完成。

尚未完成：独立待办持久队列、广场长期缓存、大账号按需加载、完整本地PDF引擎、旧队列完整迁移、全量窗口/DPI/表单交互、通知送达及安装升级/卸载验收。旧队列缺少确认基线时，历史离线回滚仍需迁移和服务端核对；新增基线保护不能代替历史迁移。

## Windows 源码入口

- `MainWindow.cs` 负责导航、页头、状态栏及仓库变更分发。`WorkspacePage.cs` 为模块提供页面挂载和通用交互。
- `Pages/Schedule` 负责日周月视图、今日待办、待安排和日程编辑。
- `Pages/Interviews` 负责面试和简历。`Pages/Experiences` 负责面经列表与详情、广场、编辑和导出。
- `Pages/AccountPage.cs`、`SettingsPage.cs` 和 `AdminPage.cs` 分别负责账号、偏好和管理员监控。
- `Controls` 存放共用控件。`Desktop` 负责托盘、随身日程和提醒。`Services` 负责 API、缓存、同步和账号资料。

## 验证与构建

Windows 原生检查 197 项通过，Python 测试 273 项通过、1 项跳过。合成纹理用例覆盖浅底深字与深底浅字的遮挡、平整背景撤去衬底、边缘渐隐及背景反算。手动切换与短时悬停仍沿用既有穿透状态机；WPF 测试窗口验证了矩形窗口的穿透、悬停恢复、提示环以及移出时恢复穿透，也覆盖日程薄边和同卡片的标题与时间。Preview 26 验证了时间表上下与右侧空白的窗口穿透、滚动后的悬停判定、任务区唤醒与手动解锁。WPF 构建通过，保留既有 WinForms 高 DPI 清单分析告警。WPF 测试窗口验证了解锁、前台通知触发采样、当前时间无底色、宽窗横线淡出及文字下方的磨砂。Preview 15 验证了窗口工作区与四边四角缩放。Preview 12 验证了预设保存、空闲延时和解锁布局。凭据测试使用模拟 HTTP 响应。随身日程离屏布局及系统滚轮钩子的注册和释放已在 Preview 4 验证。真实桌面壁纸、多显示器和混合 DPI 组合仍待验收。

## 2026-11-22界面修正

主日历时间标签改到左侧刻度附近，周视图红线仅覆盖今天的列；任务标题避开红线。日历和随身日程默认不显示已完成任务，可主动切换查看。随身日程增加HH:mm时间标签、任务起止时刻、卡片留白和自适应宽度；刷新保留滚动位置。穿透时右上角保留独立可点击的“解锁交互”浮钮，主体继续穿透，托盘恢复仍可用。

滚动条改为不占布局空间的细条：默认隐藏，用户滚动时短暂显示，停止约800毫秒后用180毫秒淡出；初始自动定位不显示滚动条。Preview 2 的窗口验收曾因用户停止界面工具中止。
