# Awesome Interview Windows 原生预览 1.5.0-W

WPF / .NET 10 原生业务页面，适配 Web 重构后的日程、账号工作时段和待安排事项。服务端代码与客户端需要同时更新；本轮没有自动部署公网服务。

## 安装与启动

解压 `AwesomeInterview-NativeDemo-1.5.0-W-win-x64.zip`，退出旧版（包括托盘），运行 `Install.cmd`。也可以直接运行 `app/AwesomeInterview.NativeDemo.exe`。这是用户级、未签名、自包含的 x64 预览包，不要求预装 .NET。安装脚本不执行服务器升级。

在应用内使用现有账号登录。密码不落盘；会话与私人缓存使用 Windows CurrentUser DPAPI 加密，并按服务地址与账号隔离。18小时有效缓存启动只校验会话，不重复下载日程；过期或显式同步时更新。会话失效、断网时仅能查看已有缓存。

## 本轮交付

- 保存、完成、删除后直接更新共享仓储；不再等待全部面经下载。缓存序列化/加密异步执行，写盘失败单独提示。
- 日历按个人工作时间裁剪跨日任务，接受 Web 的 `workday_only` 字段；三视图、日期和完成筛选使用本地数据。日历单独刷新不读取面经/简历。
- 日程表单支持岗位、地图、分条参考链接、提醒选项、重复星期、工作时段规则；会议邀请解析与入会详情继续保留。日期选择器编辑时保留精确时间。
- 重复系列可编辑/结束；单日完成独立。今日待办中增加逾期延期/完成/废除；独立待办可指定日期、新建、完成/恢复和删除，其他日期记录可展开查看。
- 日历中的“待安排”提供想法新增/编辑/放弃和已放弃列表；正式安排预填副本，取消保留原想法，重复提交不会重复创建日程。
- 快照题目按账号批量读取，新增接口沿用登录、CSRF与归属校验。原有管理员监控入口继续保留。

## 本地验证与限制

- Python：246通过、1跳过；原生契约/缓存/仓储：34项通过；Release自包含发布通过。
- Windows真实窗口确认缓存恢复、会话过期后的离线只读和操作禁用。现有会话已过期，没有进行真实账号写入。
- UI工具点击缺少几何信息，截图捕获超时；表单点击、缩放、高DPI与视觉效果仍待人工设备验收。自动测试数据为隔离夹具，不能当成真实账号联调结果。
- 提醒选项可保存；Windows系统通知送达尚未实现。简历原生渲染、面经写入/全文录入/文件导入、透明点击穿透组件、完整安装升级验收等仍在本地完整PRD中，不属于已经完成的能力。
- 公网旧服务缺少新增接口时会显示“不支持接口”，需要部署本轮服务端；不会静默回退成丢字段保存。
