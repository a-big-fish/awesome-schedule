# Awesome Interview Windows 1.6.0-W Preview 7

Windows 10/11 x64、WPF / .NET 10 原生追赶预览。面试、简历、面经录入与导出流程已接通，完整追赶PRD的全部发布门禁尚未通过。

## 安装

解压 `AwesomeInterview-NativeDemo-1.6.0-W-preview7-win-x64.zip`，先退出旧版（包括托盘），运行 `Install.cmd`；也可直接运行 `app/AwesomeInterview.NativeDemo.exe`。用户级、未签名、自包含x64包，无需预装.NET。本轮没有自动执行安装、升级或卸载。

使用现有账号在应用内登录。可主动勾选「在此电脑记住密码」。保存的凭据由 Windows 当前用户 DPAPI 加密，重登绑定原服务器与账号。退出登录会清除已保存凭据和账号缓存，也可在登录页单独清除密码。会话、快照、私人草稿、简历页和提醒账本同样加密保存。卸载保留 `%LOCALAPPDATA%/AwesomeInterviewNative` 与 `%LOCALAPPDATA%/AwesomeInterviewNativeDemo` 中的数据和桌面偏好。

## 本轮能力

- 我的面试：标题/岗位搜索、状态筛选、分页、查看日程、入会、简历与关联面经；专门的添加面试入口预选面试，通用添加仍默认个人事项。
- 简历：PDF上传/替换、进度、取消与解析等待；WPF窗口分页缩放，缓存先显示，版本变化后下载；最多两个成功版本、合计图片数据预算40MB。
- 我的面经：卡片、包含搜索、可见性筛选和分页；资料、关联面试、可选日期、编辑和删除。新建先存私密草稿，最终保存时按公开选项提交。
- 面经编辑：逐题失焦加入、双击编辑、追问、排序、分类、三类回答、感受与模块/总用时；本机自动草稿，联网自动保存正文草稿。版本冲突保留本机内容，不覆盖服务器；不完整快照禁止覆盖完整原文。
- 全文/文件：全文左右解析预览；UTF-8 Markdown和带文字层PDF导入（5MB），确认追加或替换，不提供OCR。
- 导出：分页预览；标题、分区/连续排版，独立隐藏公司、岗位、日期及三类回答；PDF/Markdown下载和预览使用同一组选项。
- 离线排期：想法与日程持久队列、来源先同步、失败依赖回滚；确认数据和乐观投影分开持久化。回执检查账号、操作和实体；未知队列版本保留原文件并阻止新更改。18小时整份缓存，日期/视图本地切换；局部日历刷新不续期面经。
- 普通会议和面试：邀请解析、校对入会链接/会议号，保存和编辑保留这些字段；简历入口在面试工作台。
- 日视图点击「回到今天」后从时间表顶部滚到当前时间。月视图将高亮日期滚到视口中央附近，遵循月历的滚动边界。
- 随身日程支持整条顶栏拖动和分区衬底。当天暂无待办时显示鼓励文案，可打开想法录入。默认隐藏已完成日程，按需显示并恢复。穿透时保留滚轮浏览。鼠标悬停约 0.8 秒可临时操作，移开后恢复穿透。右上角或托盘可关闭穿透并恢复顶栏三个按钮。
- 提醒：应用运行或留在托盘时按日程选项尝试系统托盘提醒；完成/废除/重复单日状态参与判断，去重账本防重复，合并同轮提醒，三分钟宽限后不补发陈旧提醒。
- 管理员：保留原生汇总入口，新增面试、简历、草稿、解析、导出固定监控节点，不记录私密正文或查询词。

## 服务端与限制

需要同版本源码的 `/api/mobile/v1/workspace/*`、面经接口和 `/my-schedule/idea-sync/*`。旧服务缺接口时明确报错，不能只更新安装包。本轮没有执行额外公网部署；现有服务快照、面试列表、简历状态已通过真实账号只读联调，没有写入真实数据。

PDF当前由服务端PyMuPDF生成有界PNG页，WPF原生展示并加密缓存；已缓存简历可离线阅读。这并非完整本地PDF引擎，没有文本选择/搜索，放大受渲染分辨率限制。预览支持未加密1—80页、每页不超过800万渲染像素、总PNG数据最多40MB。

提醒使用 [Windows NotifyIcon](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.notifyicon.showballoontip?view=windowsdesktop-10.0)，受系统勿扰设置影响；彻底退出后不提醒，计划通知未接入。穿透按微软[分层窗口规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)实现，真实鼠标与多DPI验收待完成。

尚未完成：独立待办持久队列、广场长期缓存、大账号按需加载、完整本地PDF引擎、旧队列完整迁移、全量窗口/DPI/表单交互、通知送达及安装升级/卸载验收。旧队列缺少确认基线时，历史离线回滚仍需迁移和服务端核对；新增基线保护不能代替历史迁移。

## Windows 源码入口

- `MainWindow.cs` 负责导航、页头、状态栏及仓库变更分发。`WorkspacePage.cs` 为模块提供页面挂载和通用交互。
- `Pages/Schedule` 负责日周月视图、今日待办、待安排和日程编辑。
- `Pages/Interviews` 负责面试和简历。`Pages/Experiences` 负责面经列表与详情、广场、编辑和导出。
- `Pages/AccountPage.cs`、`SettingsPage.cs` 和 `AdminPage.cs` 分别负责账号、偏好和管理员监控。
- `Controls` 存放共用控件。`Desktop` 负责托盘、随身日程和提醒。`Services` 负责 API、缓存、同步和账号资料。

## 2026-11-22界面修正

主日历时间标签改到左侧刻度附近，周视图红线仅覆盖今天的列；任务标题避开红线。日历和随身日程默认不显示已完成任务，可主动切换查看。随身日程增加HH:mm时间标签、任务起止时刻、卡片留白和自适应宽度；刷新保留滚动位置。穿透时右上角保留独立可点击的“解锁交互”浮钮，主体继续穿透，托盘恢复仍可用。

滚动条改为不占布局空间的细条：默认隐藏，用户滚动时短暂显示，停止约800毫秒后用180毫秒淡出；初始自动定位不显示滚动条。Preview 2 的窗口验收曾因用户停止界面工具中止。
