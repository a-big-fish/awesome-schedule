# Android 1.3 开发验收

2026-11-20，Android 15 API 35 模拟器 `emulator-5554`。所有账号、日程、面经和 PDF 均为合成数据。

| 证据 | 结果 |
| --- | --- |
| 01–06，调试 APK 的实际运行截图 | 日程合成数据、Keystore 读写和回执、面经列表、日程表单和详情、PDF 导出 |
| 07，模拟器打开飞行模式 | 原生首页立即出现新待办，标记「待同步」 |
| 08，关闭飞行模式 | 待同步标记消失。本机服务依次收到挂起操作及日历刷新，独立请求确认服务端只有一条该待办 |
| 09–11，连接本机 API | 合成 PDF 经过上传、版本核对及原生预览，管理员看板和个人设置读取线上协议的合成数据 |

日程投影和本地队列分别输出 `CalendarContract PASS` 和 `NativeOutboxContract PASS`。离线写入通过独立的 `.acceptance` 应用连接内存数据服务，服务日志记录了真实的幂等 POST。无需消息代理。Python 自动测试 259 项通过、1 项跳过，JavaScript 自动测试 100 项通过。

## 发布检查

- Android 13+ 真机当前不可用。通知权限拒绝与恢复、锁屏、重启、Doze 和实际送达时间留待真机验收。
- 模拟器的网络恢复证据覆盖了待办。日程和待安排使用同一加密队列及不同的幂等端点，完整跨账号、提醒送达和异常矩阵仍需联调。
- 本轮 APK 为调试构建 `1.0.0-alpha3`。正式签名、升版和部署等发布动作未执行。
